写记录基本用 Markdown 就够了。下面是最常用的几招，照抄就行。

## 标题

用 `#` 表示标题，几个 `#` 就是几级标题：

```
# 一级标题
## 二级标题
### 三级标题
```

## 强调

- `**加粗**` → **加粗**
- `*斜体*` → *斜体*

## 列表

无序列表用 `-`：

- 第一项
- 第二项

有序列表用数字：

1. 第一步
2. 第二步

## 链接和引用

- 链接：`[显示文字](https://example.com)`
- 引用：在行首加 `>`

> 像这样，就是一段引用。

## 代码

行内代码用反引号包起来，比如 `npm run dev`。

会这些，日常记录完全够用了。
